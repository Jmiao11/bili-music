# 方案 C：极简紧凑

覆盖设计变量、曲目行、主窗口播放栏，以及外壳和首页、搜索、收藏、歌单四页。字体沿用系统栈（PingFang SC / Microsoft YaHei）。不引入 UI 或图标库；控制器、状态和原生播放器保持原有行为。

## 外壳与四页

侧栏默认 220px，可拖动；折叠 72px。保留原宽度、持久化和 ARIA 控制。导航项高 32px、字号 13px、图标 16px、圆角 6px；按“音乐”“资料库”分组。主区与侧栏贴边，以 1px `--line` 分隔，无浮起卡片。顶部只保留标题栏品牌。底部收起、设置同为 32px 导航项。

列表表头高 32px，位于原列表滚动容器之外，与行共用 `--track-columns`。收藏和歌单没有播放量时同时收起表头与行的该列。全局 `#status` 位于标题栏窗口按钮前，使用 11px、`--text3`，错误使用危险色。

## 视觉规则

| 圆角 | 用途 |
|---|---|
| `--r-sm`，6px | 角标、图标按钮 |
| `--r-md`，10px | 列表行、输入框、普通按钮、菜单、弹出层 |
| `--r-lg`，16px | 卡片、大封面、弹窗 |
| `--r-pill`，999px | 主次操作、搜索框、筛选标签、更新小标签 |
| `--r-thumbnail`，8px | 列表及播放栏缩略图 |

- 主操作采用强调色实心胶囊。次操作采用描边胶囊，首页刷新与栏目刷新共用尺寸和样式。常规图标按钮使用原 32×32 点击区，悬停显示浅底色。播放栏的圆形播放键沿用专用尺寸。
- 搜索输入与放大镜、右端搜索按钮组成 44px 高的胶囊。普通表单输入沿用 32px 高度，使用 `--r-md`。
- 搜索的分区和排序共用一条胶囊底色，各保留原 tablist、tab 与 aria-selected。深色主题选中为浅底深字，浅色主题为深底浅字。未选中项透明，文字使用 `--text2`。
- 分 P、合集和失效角标使用浅底、6px 圆角、11px 文字及等宽数字。合集保留强调色边界。
- 曲目行普通态透明、行间无分割线。悬停和播放态均使用 10px 圆角，播放态叠加很淡的强调色并使用静态三竖条。表头平时只显示淡色文字，列宽把手在表头悬停、把手聚焦或拖动时显示。鼠标拖动、双击恢复与键盘调整继续由原表头处理。
- 搜索、歌单总览及发现音乐标题使用 28px/800。收藏、歌单详情和最近播放复用栏目页的 200px 左封面与 42px/800 右标题层级。前四个条目的封面组成 2×2，空位透出主题渐变，空列表显示整张渐变。右侧展示归属、数量及已有操作。
- 行悬停、播放底色、筛选分段与角标使用主题变量。背景图主题的行底色为半透明，并按内容区前景方案分别配色，悬停与播放态文字对比度至少为 4.5:1。

有 Key 首页显示“为你推荐”及既有描述输入行。

### 发现音乐

- 无 Key 时展示“发现音乐”（28px/800）、本地日期、“每天自动更新”和现有刷新按钮。主内容区整页滚动。
- 栏目卡片从左向右排列，间距 20px，宽度 200–260px。默认侧栏下，1080px 宽窗口预留 3 列，1280px 及以上预留 4 列。本期显示音乐热门（最多 12 首）和新歌速递（最多 8 首）。
- 卡片圆角 16px。封面高为卡宽的 90%，复用首条曲目缩略图，使用 24px 模糊和栏目渐变。无图时使用渐变。左上角显示“每日更新”，中央显示栏目名。下方 64px 标签区显示栏目名、条数和更新时间。当天显示时分，旧数据附“昨天”或月日。
- 音乐热门采用 #ff7a59 至 #d8345f 渐变，标签底色为 #6b2638。新歌速递采用 #22b8b0 至 #2450c9 渐变，标签底色为 #173d57。标签文字对比度至少 4.5:1，大标题至少 3:1。
- 悬停或键盘聚焦时出现 40px 播放键并加深阴影。卡片在常规动画设置下上浮 2px。打开与播放使用独立按钮。加载时显示同尺寸骨架卡片。无条目时标签显示“暂无内容 · 点击查看”。手动更新失败时保留旧数据并在标签中显示“更新失败”及原时间。
- 最近播放在有本地记录时展示，最多取 10 项。封面为 116px 正方形，标题与 UP 主各占一行。CSS 随内容宽度隐藏放不下的完整项。点击条目沿用最近播放页的队列和起点。“查看全部”打开最近播放页。API Key 设置提示位于首页底部。

### 栏目列表页

- “‹ 发现音乐”与侧栏“首页”返回卡片。栏目视图只在本次会话中使用。
- 页头用 200px 正方形栏目封面，右侧显示来源、栏目名（42px/800）、条数与更新时间，以及“播放全部”和单栏“刷新”。刷新和失败重试沿用 R-2 规则。空列表的失败与旧数据手动刷新失败均在页头提供重试。
- 复用曲目行，默认列为 #、标题、UP 主、播放量、时长。有多 P 条目时显示分P列。缺失时长、播放量显示“—”。列表随整页滚动，并按队列来源保留播放高亮。

搜索标题保留“搜索音乐”。搜索说明继续按原样隐藏，完整原文仍在 DOM。收藏加载错误仍显示。

侧栏在“我的歌单”下列出名称与首数（13px / 11px），当前详情项使用 `--nav-active`，折叠时隐藏子列表。点击侧栏歌单复用 setActiveView 后 choosePlaylist，点击“我的歌单”回总览。总览为 44px 歌单行及原有导入和新建按钮。详情页头保留改名和删除。新建进入详情，删除当前歌单回总览。总览与详情使用 library.view.playlistDetail 临时展示状态，沿用既有 selectedPlaylistId 回选规则。

背景图只由 `--glass-blur` 控制模糊，scale(1.08) 避免透明边；0档为原图。整窗遮罩位于背景与内容之间，颜色、有效强度与可读性见 UI-6b。背景滑块仍保存到原 background-dim，范围0–95、默认90；侧栏、标题栏、页头、列表和播放栏透明，仅分隔线分区。动态主题不使用图片遮罩，视觉及三色动画不变。

浮层样式位于 `ui/styles.css` 末尾的独立浮层区段（入口 CSS 须与产物逐字一致，不使用 @import）。沉浸页继续使用不透明 `--floating-surface`（深 #232428、浅 #FAFAFB、背景图 #202024、动态 #16181C）；设置/资料库/分P对话框、帮助气泡和播放提示使用独立 `--surface`。深色 #232428，浅色 #FAFAFB；背景图为 rgba(24,25,28,.78) 加 blur(24px) saturate(1.2)，不支持 backdrop-filter 时回退 #232428；动态为 #16181C 混入当前封面色8%的不透明表面。均不继承页面 `--panel`。尺寸与遮罩按下述 UI-3 规范，开关阶段与模态层级不变；沉浸页打开时仅将标题栏提升到41层（沉浸页40、模态50），确保窗口按钮和拖动区可用。迷你窗使用独立CSS隔离页面规则，并通过现有同步通道复用主窗主题参数。

40档原例外（用户裁定）：实际背景图最亮处的纯白主文字约4.23:1，保留上述指定公式，不额外描边或提高遮罩；70及以上档位仍按三个文字 token ≥4.5:1 验收。

主内容左右边距20px。侧栏顶部内边距8px，组标题约25px高，导航项仍32px；默认220px/折叠72px及拖动持久化不变。首页输入行后无额外16px margin。首页与其他页面共用上述列宽；分P/合集/失效角标在独立分P列显示，不再紧随标题。表头和列表共同表面内均使用 scrollbar-gutter:stable、scrollbar-width:thin，长短列表预留相同槽位；表头仍在滚动容器外。窄窗容器查询由共用表面承载，避免滚动条使表头/行在不同断点切换。

后续 UI 批次若样式误伤原有文字的可见性，直接恢复原状并在报告登记；真正新增、删除、替换文字或涉及冻结断言、控制器、G0 时，仍按任务要求先申请。搜索结果页头继续隐藏，避免通用页头样式将原有隐藏文案显示出来。

## 播放栏与兼容边界

顶部进度条沿用原生 range。左侧第一行曲名单行省略；第二行显示 UP 主及已有的所属视频信息，随后以装饰点分隔合集位置、分 P 下拉和跳过键。两行在 64px 播放栏内垂直居中。副标题先让出 UP 主文字空间，曲名独立使用第一行宽度；位置和两个操作均不折行、不截断。普通单 P 隐藏该组，单 P 合集仍显示成员位置与跳过。分 P 与跳过点击高 28px，取消组框及分隔线。

中央保持等宽左右列、两端各 40px 的时间与对称五键，播放键中心偏差不超过 1px。右侧按 DOM 顺序分为收藏／加入歌单、沉浸歌词／在 B 站打开／播放队列、音质／音量三组。组内 4px、组间 16px，≤1180px 时分别收为 2px、10px。封面与独立歌词按钮均可进入沉浸页。队列入口用列表音符图标和 11px 等宽数字保留父条目计数，空队列禁用。音质点击高 32px；音量保留喇叭与细轨，range 命中高 32px，组内音量宽度宽窗 92px、窄窗 72px。背景图主题用区域色板的实色底保护副标题对比度。

## UI-2b：沉浸页与保留项

沉浸页铺满窗口，外框无 margin、圆角、边框、阴影或灰色遮罩。根节点保持独立不透明底（沿用 --floating-surface：深色 #232428、背景图 #202024、浅色 #FAFAFB、动态 #16181C），封面以 blur(80px) 铺底，再叠加主题底色 75%（浅色 82%）。不影响其他浮层的 --floating-surface。由原 immersiveOpen 驱动 .app-shell.immersive-open；打开时标题栏透明且无底边，保留原窗口按钮、状态文字、拖动和层级。

保留原左栏封面、曲名、进度、控制/操作按钮及歌词校准，右栏歌词；当前句 22px/600/--text，其余 18px/--text3。收起按钮位于右上角，高 28px。hidden/is-open、焦点、Esc、获取/滚动和 FIX-1 防重入不变。

UI-2b补充授权恢复可调列宽与封面按钮：每个表头仅两个委托监听，拖动期间只投影文档根CSS变量；使用 bilibili-music.track-columns 保存标题自适应/固定宽度及四项数字列宽，非法回退。封面新增按钮复用原沉浸页回调，原按钮保留。规格、持久化与G0重建记录见 [列宽设计](design/track-columns.md)。

## UI-3：设置与浮层

`--r-md:8px` 用于弹窗等独立表面；`--surface` 是独立不透明 `--floating-surface` 的别名。`--overlay` 为深色类 rgba(0,0,0,.45)、浅色 rgba(0,0,0,.25)；`--dialog-shadow` 为 0 12px 32px rgba(0,0,0,.35)，浅色 alpha .12。沿用主题逻辑，不依赖页面透明背景。

小号弹窗420px（确认、新建/改名、加入歌单），中号560px（导入收藏夹、分P、帮助）。最大80vh，内容可滚动。弹窗使用 1px `--line`、`--r-lg` 和 `--dialog-shadow`，帮助气泡作为弹出层使用 `--r-md`。标题行48px、15px/600，设置关闭图标点击区32px。内容内边距16px 20px，底部56px，次要按钮在左、主按钮在右，删除和清理主按钮用危险色。既有说明文字保留在标题行下方，必要时增加说明区高度。分P弹窗沿用底部“关闭”。

弹窗列表保持40px行高，悬停使用 `--hover`，选中使用 `--active`。输入高32px，按钮高28px，圆角遵循视觉规则。Toast 和播放提示使用 `--surface`、1px `--line`、`--r-md` 和12px文字。全局可聚焦控件焦点环使用2px `--accent`，外偏移2px。

## UI-4：参数与跨窗表面

背景图显示“选择/恢复图片”和模糊、暗化两项滑块，没有位置或缩放控件。`bilibili-music.background-path` 继续只存路径，由 Rust 读图返回 data URL；不把原始路径写进 CSS。`glass-blur` 范围0–80、默认40，驱动 `--glass-blur` 和图片实际模糊；额外面板透明度固定0，`bilibili-music.panel-alpha` 旧键和值原样保留，程序不读取、写入或删除；`background-dim` 范围0–95、默认90，驱动 `--background-dim`，遮罩按上述连续两段映射0%–95%。动态主题不读取背景图参数，现有控件禁用行为不变。

深色 `--text3` 在选中导航底 #2A2C31 上为4.42:1，因此选中侧栏歌单及总览歌单的首数使用 `--text2`（6.71:1）；不改全局token。普通/悬停/当前行的三个文字token均≥4.5:1。

迷你窗在既有 `mini-player-state` 中按主题追加 `backgroundPath`、`backgroundDim`、同路径图片替换所需的临时版本号 `backgroundVersion`，或 `dynamicColors`，深/浅色有效载荷保持原字段。复用 Rust `load_background_image`，路径或图片版本变化时异步读图，迟到读图结果不能覆盖新主题/新图片。图像居中cover，blur(24px)、scale(1.15)，遮罩与主窗同公式；动态主题复用主窗三色、渐变、25秒完整循环、1.2秒切色过渡和减少动态效果规则。不新增通道或启动监听；不写入新存储。


## UI-5 动态背景与列宽

动态背景沿用32×32离屏canvas及现有封面事件，无额外请求。5位量化依次选主色、鲜艳色、辅助色；同频按量化键稳定排序，三色目标相对亮度分别为.055/.08/.045。灰度/空采样回退两种柔和中性色和30%强调色；无封面时保留上一组。底色#303640，三处径向色块以transform/opacity做25秒循环，切色用两层opacity过渡1.2秒，不用JS动画计时器。隐藏窗口暂停，prefers-reduced-motion静止。--text/#f7f9fc、--text2/#e1e6ec、--text3/#d0d9e3，危险文字#ffcaca；强调文字混白60%，确保最亮色块与叠加行状态下可读。动态弹窗为底色混入主色10%；迷你窗复用原三色同步字段及同一组件/渐变规则，仅迷你窗自身增加visibilitychange用于暂停，不影响主窗G0。

列宽见[列宽设计](design/track-columns.md)。新提示“拖动调整列宽,双击恢复默认”允许显示，原可见文案保持，唯一隐藏项为“面板不透明度”及数值。


### UI-5补充：无横向溢出的列宽

表头、列表、外层track-surface均overflow-x:hidden，取消正的min-width撑宽。偏好宽度仅来自原存储；有效宽度由共享CSS列模板计算：先把标题压至240，再按其他列“偏好−最小”的可压缩余量比例收缩，保留最小值。容器≤780px收起播放量、≤716px收起日期及分P、≤652px收起UP主、≤552px收起时长；表头与行同时收起对应轨道。原应用最小窗口1080px不变；320px侧栏下仅需第一档收起。window/侧栏/偏好变化均由CSS即时重算，没有新增监听、observer或重写偏好，扩大后恢复用户设定。窗口缩放时使用上述收缩；拖动时按UI-6冻结标题并以弹性空白限位，不触发这套收缩。

### UI-6b：背景图整窗方案与低档适配

已有96px离屏采样按窗口居中cover并scale(1.08)。仅图片变化时，以裁剪后整图平均相对亮度Lavg决定整窗方案：≥.50浅色、≤.42深色；中间保留上次，首次以.46分界。滑块和窗口尺寸变化不重算整窗方案；低档区域几何变化复用已解码图片和缓存像素。解码失败保留上次方案，迟到任务丢弃。

遮罩名为“背景遮罩”，存储键、范围0–95、默认90不变。基础映射0–40→0–55%，40–95→55–95%。浅色方案用rgb(250,250,251)，深色用rgb(10,12,16)。用户单项裁定以实际4.5:1优先：基础遮罩≥55%时，深色方案有效遮罩至少65%（白色亮斑叠9%当前行也可读）；浅色方案沿原映射。低于55%沿基础值，不抬高遮罩。

背景图专用前景（仅该主题）：浅色方案text/text2/text3为#000/#080808/#101010，深色为#fff/#fafafa/#f4f4f4。图标、表头、UP主、日期、时间、播放栏使用同一套；强调色文字分别混8%强调色与黑、4%强调色与白，以保持对比度。浅色主按钮采用强调色60%与黑色混合、白字；深色主按钮仍强调色底、深字。输入/角标用实色底和本地边界，播放键本地反色。浅色hover/active/nav-active为黑色5%/8%/8%；深色为白色6%/9%/9%。其他三种主题不变。

最新单项裁定保留低档自适应：基础遮罩<55%时，仅标题栏/侧栏/主区/播放栏使用data-image-region-scheme声明区域前景，按缓存亮度、当前遮罩色及.45/.38滞回切换；高档不输出区域属性，整窗统一。所有图片模式文字阴影与图标光晕已移除。遮罩≥55%时三级文字以实际渲染后≥4.5:1验收；低于55%由用户自行取舍，不保证混杂区域4.5:1。

迷你窗通过既有同步通道追加imageScheme（非持久化字段），使用同一专用前景与有效遮罩公式。浮层沿用视口图像、blur24px/scale1.15，颜色跟随整窗方案，alpha=max(主窗有效值,55%)；低档深色浮层至少65%，保证白色亮斑可读。不使用backdrop-filter，动态浮层不变。

### 列宽与浮层几何

非标题分隔线按下时，将当前渲染标题宽度固定，只用末端弹性空白供本次拖动增减；空白耗尽即停止，不挤标题或其他列。双击标题分隔线恢复auto；窗口缩小仍按标题优先、数值列比例压缩的既有策略适配，不回写偏好。分P播放小控件使用所在播放栏区域的次要文字、图标和悬停色。

图像浮层使用同一张图的视口坐标、24px模糊和1.15倍放大，遮罩见UI-6b，颜色跟随整窗方案；不用backdrop-filter。动态浮层复用三色组件、流动动画和减少动态效果规则。背景层以视口固定并裁剪到浮层内侧1px，边框/圆角/阴影/尺寸保持，内容滚动不移动背景。浮层采用UI-6b同一整窗前景，不再独立采样切色。深浅主题保持原来的不透明表面。

帮助/设置等原生展开和滚动通过用户单项授权的浮层几何端口刷新：每个可见浮层的已挂载背景观察所属表面尺寸，仅设置/资料库/分P表面安装局部scroll；卸载时disconnect/remove。默认启动不挂载该端口，G0不变。队列抽屉透明，图片和动态主题直接显示全窗的背景图、遮罩或三色层，深浅色显示与主区一致的 `--root`。图片基础遮罩低于 55% 时，打开的抽屉以最终占用位置作为独立区域，复用缓存像素、区域前景算法和滞回，原四区继续按原矩形判定。关闭时移除此区域，高档沿用整窗方案。

### UI-6b 补充：提示按钮、标题交换与浮层滚动

发现音乐底部的“去设置”使用 12px 文字链接样式，沿用原回调。推荐首页的“去设置”使用 28px 描边次要胶囊。跳过图标沿用当前图标色。
