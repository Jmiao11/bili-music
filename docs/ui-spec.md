覆盖设计变量、曲目行、主窗口播放栏，以及外壳和首页、搜索、收藏、歌单四页。字体沿用系统栈（PingFang SC / Microsoft YaHei）。不引入 UI 或图标库；控制器、状态和原生播放器保持原有行为。

## 外壳与四页

侧栏默认 220px，可拖动；折叠 72px。保留原宽度、持久化和 ARIA 控制。导航项高 32px、字号 13px、图标 16px、圆角 6px；按“音乐”“资料库”分组。主区与侧栏贴边，以 1px `--line` 分隔，无浮起卡片。顶部只保留标题栏品牌。底部收起、设置同为 32px 导航项。

页头高 56px、标题 18px/600，说明同行 12px/`--text3` 或按授权隐藏。次要按钮高 28px、透明底、`--line2` 边框；主按钮高 28px、强调色底；输入高 32px、`--input` 底。列表表头高 32px，位于原列表滚动容器之外、普通文档流中，背景透明，仅有 1px 底线，与行共用 `--track-columns`；收藏和歌单没有播放量时同时收起表头与行的该列。全局 `#status` 保留原 role 与文案，移至标题栏窗口按钮前，11px/`--text3`，错误使用危险色。

首页标题和 48px 描述输入行的显示完全沿用原逻辑；不固定成“为你推荐”。搜索标题保留“搜索音乐”，输入与搜索按钮成组靠左、紧随标题，二者间距 8px，输入最大宽 520px 且可收缩；筛选标签高 28px、当前项灰底。搜索说明继续按原样隐藏，完整原文仍在 DOM。收藏首数为普通文字，正常说明隐藏，加载错误仍显示。

侧栏在“我的歌单”下列出名称与首数（13px / 11px），当前详情项使用 --nav-active；折叠时隐藏子列表。点击侧栏歌单复用 setActiveView 后 choosePlaylist；点击“我的歌单”回总览。总览为 44px 歌单行及原有导入/新建按钮，详情只显示 132px 页头与曲目列表，含 96px 的 2×2 拼图、24px/700 歌单名与改名/删除按钮；不足四张封面时保留 --line2 空格。新建进入详情，删除当前歌单回总览。总览/详情使用 library.view.playlistDetail 临时展示状态，不持久化，保留既有 selectedPlaylistId 回选规则。不新增播放全部/随机播放行为。

背景图只由 `--glass-blur` 控制模糊，scale(1.08) 避免透明边；0档为原图。整窗遮罩位于背景与内容之间，颜色、有效强度与可读性见 UI-6b。背景滑块仍保存到原 background-dim，范围0–95、默认90；面板不透明度兼容节点及监听保留但隐藏，原值不生效、不清除。侧栏、标题栏、页头、列表和播放栏透明，仅分隔线分区。动态主题不使用图片遮罩，视觉及三色动画不变。隐藏的本地音乐兼容节点不可聚焦、aria-hidden，原启动监听保留；本地功能落地或批准重建G0后可删除。

浮层样式位于 `ui/styles.css` 末尾的独立浮层区段（入口 CSS 须与产物逐字一致，不使用 @import）。沉浸页继续使用不透明 `--floating-surface`（深 #232428、浅 #FAFAFB、背景图 #202024、动态 #16181C）；设置/资料库/分P对话框、帮助气泡和播放提示使用独立 `--surface`。深色 #232428，浅色 #FAFAFB；背景图为 rgba(24,25,28,.78) 加 blur(24px) saturate(1.2)，不支持 backdrop-filter 时回退 #232428；动态为 #16181C 混入当前封面色8%的不透明表面。均不继承页面 `--panel`。尺寸与遮罩按下述 UI-3 规范，开关阶段与模态层级不变；沉浸页打开时仅将标题栏提升到41层（沉浸页40、模态50），确保窗口按钮和拖动区可用。迷你窗使用独立CSS隔离页面规则，并通过现有同步通道复用主窗主题参数。

40档原例外（用户裁定）：实际背景图最亮处的纯白主文字约4.23:1，保留上述指定公式，不额外描边或提高遮罩；70及以上档位仍按三个文字 token ≥4.5:1 验收。

主内容左右边距20px。侧栏顶部内边距8px，组标题约25px高，导航项仍32px；默认220px/折叠72px及拖动持久化不变。首页输入行后无额外16px margin。首页与其他页面共用上述列宽；分P/合集/失效角标在独立分P列显示，不再紧随标题。表头和列表共同表面内均使用 scrollbar-gutter:stable、scrollbar-width:thin，长短列表预留相同槽位；表头仍在滚动容器外。680px容器查询由共用表面承载，避免滚动条使表头/行在不同断点切换。

后续 UI 批次若样式误伤原有文字的可见性，直接恢复原状并在报告登记；真正新增、删除、替换文字或涉及冻结断言、控制器、G0 时，仍按任务要求先申请。搜索结果页头继续隐藏，避免通用页头样式将原有隐藏文案显示出来。

## 播放栏与兼容边界

顶部贯穿的原生 range 沿用 pointerdown/input/change 回调。左侧显示封面、曲名与 UP 主/所属视频；现有分P控件与跳过按钮在同一组，移到右侧功能区最左边，多 BV 合集额外显示已有快照的成员进度。中间视觉顺序为随机、上一首、播放/暂停、下一首、循环，两侧显示时间。右侧视觉顺序为分P/合集小控件、队列计数、收藏、加入歌单、沉浸页与歌词入口、B站、音量。

播放栏使用等宽左右列和auto中列（可收缩的1fr / auto / 1fr）；两侧时间预留同宽40px，中间五键对称排列，播放键中心与窗口中心偏差不超过2px。左栏曲名截断；多P控件不占左栏空间，右栏控件不影响中列位置。保留原生窗口最小1080×600及原有尺寸约束。

为保持冻结 DOM 与 G0，事件节点的源码安装顺序不变，视觉重排使用 CSS Grid/Flex。原封面上的沉浸页按钮移至右侧，aria-label 与回调不变；队列只保留已有计数，不伪造队列面板功能。`♪1/30`、收藏字符和失效 `!` 原文保留在 DOM，SVG/样式负责新外观；全部按钮的标签、禁用条件与点击行为沿用原值。多P与合集共用原跳过回调，不新建播放流程。audio 始终留在 Vue 宿主外。

沉浸页铺满窗口，外框无 margin、圆角、边框、阴影或灰色遮罩。根节点保持独立不透明底（沿用 --floating-surface：深色 #232428、背景图 #202024、浅色 #FAFAFB、动态 #16181C），封面以 blur(80px) 铺底，再叠加主题底色 75%（浅色 82%）。不影响其他浮层的 --floating-surface。由原 immersiveOpen 驱动 .app-shell.immersive-open；打开时标题栏透明且无底边，保留原窗口按钮、状态文字、拖动和层级。

保留原左栏封面、曲名、进度、控制/操作按钮及歌词校准，右栏歌词；当前句 22px/600/--text，其余 18px/--text3。收起按钮位于右上角，高 28px。hidden/is-open、焦点、Esc、获取/滚动和 FIX-1 防重入不变。

UI-2b补充授权恢复可调列宽与封面按钮：每个表头仅两个委托监听，拖动期间只投影文档根CSS变量；使用 bilibili-music.track-columns 保存标题自适应/固定宽度及四项数字列宽，非法回退。封面新增按钮复用原沉浸页回调，原按钮保留。规格、持久化与G0重建记录见 [列宽设计](design/track-columns.md)。

## UI-3：设置与浮层

`--r-md:8px` 仅用于弹窗和抽屉；`--surface` 是独立不透明 `--floating-surface` 的别名。`--overlay` 为深色类 rgba(0,0,0,.45)、浅色 rgba(0,0,0,.25)；`--dialog-shadow` 为 0 12px 32px rgba(0,0,0,.35)，浅色 alpha .12。沿用主题逻辑，不依赖页面透明背景。

小号弹窗420px（确认、新建/改名、加入歌单），中号560px（导入收藏夹、分P、帮助）；最大80vh，内容可滚动。边框1px `--line`、圆角 `--r-md`、阴影 `--dialog-shadow`。标题行48px、15px/600，右侧关闭按钮28px；内容16px 20px；底部56px，次要按钮在左、主按钮在右，删除/清理主按钮用危险色。既有说明文字保留在标题行下方，必要时增加说明区高度，不截掉文字去凑48px。分P弹窗沿用底部“关闭”，不新增头部回调。

设置仍为原模态，页头56px，内容最大720px靠左；所有分组、顺序、说明与 details 展开行为不变。分组标题11px/600/`--text3`，上方24px；设置行最小48px，用1px `--line` 分隔。名称13px `--text`，说明12px `--text3`，右侧控件右对齐。复选框保持原生方形勾选框，不改成开关。

迷你窗保持既有尺寸、DOM结构、控件集合与窗口行为；`--mini-bg` 映射独立 `--bar` 色板，使用 `--line` 分隔、16px图标、32px圆形反色播放键、13px主文字和12px提示。UI-4已通过原通道补充背景图/暗化与动态配色，四种主题直接呈现；没有播放进度数据，仍不伪造进度线，2px真实进度留后续接线。

## UI-4：参数与跨窗表面

背景图显示“选择/恢复图片”和模糊、暗化两项滑块，没有位置或缩放控件。`bilibili-music.background-path` 继续只存路径，由 Rust 读图返回 data URL；不把原始路径写进 CSS。`glass-blur` 范围0–80、默认40，驱动 `--glass-blur` 和图片实际模糊；`panel-alpha` 旧键和值保留；兼容控件隐藏，额外面板透明度固定0，不再读取或应用；`background-dim` 范围0–95、默认90，驱动 `--background-dim`，遮罩按上述连续两段映射0%–95%。动态主题不读取背景图参数，现有控件禁用行为不变。

深色 `--text3` 在选中导航底 #2A2C31 上为4.42:1，因此选中侧栏歌单及总览歌单的首数使用 `--text2`（6.71:1）；不改全局token。普通/悬停/当前行的三个文字token均≥4.5:1。

迷你窗在既有 `mini-player-state` 中按主题追加 `backgroundPath`、`backgroundDim`、同路径图片替换所需的临时版本号 `backgroundVersion`，或 `dynamicColors`，深/浅色有效载荷保持原字段。复用 Rust `load_background_image`，路径或图片版本变化时异步读图，迟到读图结果不能覆盖新主题/新图片。图像居中cover，blur(24px)、scale(1.15)，遮罩与主窗同公式；动态主题复用主窗三色、渐变、25秒完整循环、1.2秒切色过渡和减少动态效果规则。不新增通道或启动监听；不写入新存储。


## UI-5 动态背景与列宽

动态背景沿用32×32离屏canvas及现有封面事件，无额外请求。5位量化依次选主色、鲜艳色、辅助色；同频按量化键稳定排序，三色目标相对亮度分别为.055/.08/.045。灰度/空采样回退两种柔和中性色和30%强调色；无封面时保留上一组。底色#303640，三处径向色块以transform/opacity做25秒循环，切色用两层opacity过渡1.2秒，不用JS动画计时器。隐藏窗口暂停，prefers-reduced-motion静止。--text/#f7f9fc、--text2/#e1e6ec、--text3/#d0d9e3，危险文字#ffcaca；强调文字混白60%，确保最亮色块与叠加行状态下可读。动态弹窗为底色混入主色10%；迷你窗复用原三色同步字段及同一组件/渐变规则，仅迷你窗自身增加visibilitychange用于暂停，不影响主窗G0。

列宽见[列宽设计](design/track-columns.md)。新提示“拖动调整列宽,双击恢复默认”允许显示，原可见文案保持，唯一隐藏项为“面板不透明度”及数值。


### UI-5补充：无横向溢出的列宽

表头、列表、外层track-surface均overflow-x:hidden，取消正的min-width撑宽。偏好宽度仅来自原存储；有效宽度由共享CSS列模板计算：先把标题压至240，再按其他列“偏好−最小”的可压缩余量比例收缩，保留最小值。容器≤744px收起播放量、≤680px收起日期及分P、≤616px收起UP主、≤516px收起时长；表头与行同时收起对应轨道。原应用最小窗口1080px不变；320px侧栏下仅需第一档收起。window/侧栏/偏好变化均由CSS即时重算，没有新增监听、observer或重写偏好，扩大后恢复用户设定。窗口缩放时使用上述收缩；拖动时按UI-6冻结标题并以弹性空白限位，不触发这套收缩。

### UI-6b：背景图整窗方案与低档适配

已有96px离屏采样按窗口居中cover并scale(1.08)。仅图片变化时，以裁剪后整图平均相对亮度Lavg决定整窗方案：≥.50浅色、≤.42深色；中间保留上次，首次以.46分界。滑块和窗口尺寸变化不重算整窗方案；低档区域几何变化复用已解码图片和缓存像素。解码失败保留上次方案，迟到任务丢弃。

遮罩名为“背景遮罩”，存储键、范围0–95、默认90不变。基础映射0–40→0–55%，40–95→55–95%。浅色方案用rgb(250,250,251)，深色用rgb(10,12,16)。用户单项裁定以实际4.5:1优先：基础遮罩≥55%时，深色方案有效遮罩至少65%（白色亮斑叠9%当前行也可读）；浅色方案沿原映射。低于55%沿基础值，不抬高遮罩。

背景图专用前景（仅该主题）：浅色方案text/text2/text3为#000/#080808/#101010，深色为#fff/#fafafa/#f4f4f4。图标、表头、UP主、日期、时间、播放栏使用同一套；强调色文字分别混8%强调色与黑、4%强调色与白，以保持对比度。浅色主按钮采用强调色60%与黑色混合、白字；深色主按钮仍强调色底、深字。输入/角标用实色底和本地边界，播放键本地反色。浅色hover/active/nav-active为黑色5%/8%/8%；深色为白色6%/9%/9%。其他三种主题不变。

最新单项裁定保留低档自适应：基础遮罩<55%时，仅标题栏/侧栏/主区/播放栏使用data-image-region-scheme声明区域前景，按缓存亮度、当前遮罩色及.45/.38滞回切换；高档不输出区域属性，整窗统一。所有图片模式文字阴影与图标光晕已移除。遮罩≥55%时三级文字以实际渲染后≥4.5:1验收；低于55%由用户自行取舍，不保证混杂区域4.5:1。

迷你窗通过既有同步通道追加imageScheme（非持久化字段），使用同一专用前景与有效遮罩公式。浮层沿用视口图像、blur24px/scale1.15，颜色跟随整窗方案，alpha=max(主窗有效值,55%)；低档深色浮层至少65%，保证白色亮斑可读。不使用backdrop-filter，动态浮层不变。

### 列宽与浮层几何

非标题分隔线按下时，将当前渲染标题宽度固定，只用末端弹性空白供本次拖动增减；空白耗尽即停止，不挤标题或其他列。双击标题分隔线恢复auto；窗口缩小仍按标题优先、数值列比例压缩的既有策略适配，不回写偏好。分P播放小控件使用所在播放栏区域的input/line2/text2/icon/hover。

图像浮层使用同一张图的视口坐标、24px模糊和1.15倍放大，遮罩见UI-6b，颜色跟随整窗方案；不用backdrop-filter。动态浮层复用三色组件、流动动画和减少动态效果规则。背景层以视口固定并裁剪到浮层内侧1px，边框/圆角/阴影/尺寸保持，内容滚动不移动背景。浮层采用UI-6b同一整窗前景，不再独立采样切色。深浅主题保持原来的不透明表面。

帮助/设置等原生展开和滚动通过用户单项授权的浮层几何端口刷新：每个可见浮层的已挂载背景观察所属表面尺寸，仅设置/资料库/分P表面安装局部scroll；卸载时disconnect/remove。默认启动不挂载该端口，G0不变。队列现有能力仍仅计数，没有抽屉，不新增业务功能。

### UI-6b 补充：提示按钮、标题交换与浮层滚动

首页“去设置”沿用原按钮/回调，所有主题统一为28px透明次要按钮、1px line2、r-sm、13px text，无下划线。列表分P/合集角标和播放栏分P组统一以currentColor混透明：底8%、边22%、悬停14%，文字text2；合集边框仍用accent，跳过图标沿当前图标色。

标题/UP主分隔线仅在两列间等量交换，不使用弹性空白。按下时auto标题固定为实际宽；向右由UP主让宽至100，向左由标题让宽至240或UP主增至320；其他线保持固定。表头禁用原生文字选择以避免浏览器启动文字拖放并pointercancel。用户实际完成这类交换时保存当前可见布局，避免释放后旧偏好再次适配移动边界；隐藏列保留合法的旧偏好。单独窗口缩放仍不写存储。双击恢复标题auto；其他分隔线保持UI-6规则。

设置头部移出滚动区，settings-content独立滚动；背景装饰覆盖整张表面，头部与正文只用line分隔。资料库/合集/导入/确认复用头部在body外的结构，分P标题在list外；帮助气泡没有独立固定头部。原浮层几何端口以同一个捕获阶段scroll监听处理后代滚动，数量与G0均不变，卸载仍配对清理。
