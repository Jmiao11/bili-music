# 方案 C：极简紧凑

覆盖设计变量、曲目行、主窗口播放栏，以及外壳和首页、搜索、收藏、歌单四页。字体沿用系统栈（PingFang SC / Microsoft YaHei）。不引入 UI 或图标库；控制器、状态和原生播放器保持原有行为。

主按钮文字使用 `--on-accent`（深色类主题 #111214，浅色主题 #fff，适配原有较深的强调色），错误提示使用 `--danger`（深色类 #FF8080，浅色 #B42332）。

强调色只用于当前曲目名/跳动条、进度、开启的随机/循环、主按钮、合集角标和当前导航图标；收藏及普通操作使用灰阶。原有焦点轮廓保留以保护键盘可见性。

背景图沿用 Rust 生成的 data URL 及原有暗化滑块；实际遮罩尊重用户保存值，不把现有 90% 默认值强改为规范示意的 80%。动态光晕仍由原双层取色与淡化机制提供；播放栏的 `--cover-color` 直接映射当前前景层已有颜色，不重新取色、订阅或计时。

## 外壳与四页

侧栏默认 220px，可拖动；折叠 72px。保留原宽度、持久化和 ARIA 控制。导航项高 32px、字号 13px、图标 16px、圆角 6px；按“音乐”“资料库”分组。主区与侧栏贴边，以 1px `--line` 分隔，无浮起卡片。顶部只保留标题栏品牌。底部收起、设置同为 32px 导航项。

页头高 56px、标题 18px/600，说明同行 12px/`--text3` 或按授权隐藏。次要按钮高 28px、透明底、`--line2` 边框；主按钮高 28px、强调色底；输入高 32px、`--input` 底。列表表头高 32px，位于原列表滚动容器之外、普通文档流中，背景透明，仅有 1px 底线，与行共用 `--track-columns`；收藏和歌单没有播放量时同时收起表头与行的该列。全局 `#status` 保留原 role 与文案，移至标题栏窗口按钮前，11px/`--text3`，错误使用危险色。

首页标题和 48px 描述输入行的显示完全沿用原逻辑；不固定成“为你推荐”。搜索标题保留“搜索音乐”，输入与搜索按钮成组靠左、紧随标题，二者间距 8px，输入最大宽 520px 且可收缩；筛选标签高 28px、当前项灰底。搜索说明继续按原样隐藏，完整原文仍在 DOM。收藏首数为普通文字，正常说明隐藏，加载错误仍显示。

歌单页复用原有选择与详情：44px 歌单选择行位于内容顶部，详情头高 132px，包含 96px 的 2×2 封面拼图、24px/700 歌单名和现有改名/删除按钮。侧栏不列歌单：原页面切换为控制器私有函数，按本批裁定采用不接线的降级方案；不新增总览/详情路由或播放全部/随机播放行为。

背景图使用整窗 `.window-background-overlay`：位于图片上方、所有内容下方，不接收指针。`background-dim` 保存范围 40–95、默认 90，直接除以 100 作为全局暗色遮罩不透明度；40/70/95 分别对应 40%/70%/95%，存储格式及默认值不改。

标题栏、侧栏、页头/输入行、筛选行、歌单选择区、表头与曲目共同表面、播放栏使用无圆角/阴影/边框的局部伪元素层，pointer-events:none，backdrop-filter:blur(12px)。不支持模糊时仍保留暗化。与全局层同用 rgb(10,12,16)；全局 alpha 为 g，局部 alpha 为 `clamp(0, (.86 - g) / (1 - g), 1)`，合成 alpha 为 `max(g,.86)`。40/70/95 档局部约 76.7%/53.3%/0；86% 下限包含悬停4%、当前行7%、导航选中9%的白色叠层预算，文字区 `--text`/`--text2`/`--text3` 均需达到4.5:1。局部表面随实际内容结束，短列表下方及页面边距只保留全局层，不恢复浮动卡片。body 保留隔离层叠上下文。动态主题保留原封面光晕和取色，不使用图片遮罩。未选中筛选、歌单行使用 `--text2`、opacity:1。隐藏的本地音乐兼容节点不可聚焦、aria-hidden，原启动监听保留；本地功能落地或批准重建 G0 后可删除。

主内容左右边距20px。侧栏顶部内边距8px，组标题约25px高，导航项仍32px；默认220px/折叠72px及拖动持久化不变。首页输入行后无额外16px margin。首页UP主轨140px；无角标时曲名跨过空角标轨，消除额外间隙。表头和列表共同表面内均使用 scrollbar-gutter:stable、scrollbar-width:thin，长短列表预留相同槽位；表头仍在滚动容器外。680px容器查询由共用表面承载，避免滚动条使表头/行在不同断点切换。

后续 UI 批次若样式误伤原有文字的可见性，直接恢复原状并在报告登记；真正新增、删除、替换文字或涉及冻结断言、控制器、G0 时，仍按任务要求先申请。搜索结果页头继续隐藏，避免通用页头样式将原有隐藏文案显示出来。

## 五种行状态

| 状态 | 展示 |
|---|---|
| 默认 | 44px 平行行，只有 `--line` 底线；灰色序号；操作 visibility:hidden，保留位置 |
| 悬停 | `--hover` 背景；播放图标替代序号；显示收藏/加入歌单；UP 主下划线，无新增点击 |
| 当前播放 | `--active` 背景；原三条跳动条；曲名 `--accent-text`、600；无彩色描边或整行染色 |
| 失效 | 曲名 `--text3` 与删除线；封面 40%；显示“已失效”角标 |
| 拖动 | 源行 55%；依原 before/after 方向在插入位置绘制 2px 强调线；悬停/拖动显示把手 |

键盘进入行后同时显示操作与焦点轮廓。减少动态效果时停止跳动条动画。拖动继续由整行原生会话处理，装饰把手不增加第二套拖拽事件。角标 DOM 顺序保留在 `.track-actions`，以 subgrid 对齐到标题旁；不新增“更多”按钮。

## 播放栏与兼容边界

顶部贯穿的原生 range 沿用 pointerdown/input/change 回调。左侧显示封面、曲名与 UP 主/所属视频；现有分P控件与跳过按钮在同一组，多 BV 合集额外显示已有快照的成员进度。中间视觉顺序为随机、上一首、播放/暂停、下一首、循环，两侧显示时间。右侧为收藏、加入歌单、沉浸页与歌词入口、队列计数、B站、音量。

播放栏使用等宽左右列和auto中列（可收缩的1fr / auto / 1fr）；两侧时间预留同宽40px，中间五键对称排列，播放键中心与窗口中心偏差不超过2px。左栏曲名截断，多P控件浮在左栏末端；队列计数预留64px，不影响中列位置。保留原生窗口最小1080×600及原有尺寸约束。

为保持冻结 DOM 与 G0，事件节点的源码安装顺序不变，视觉重排使用 CSS Grid/Flex。原封面上的沉浸页按钮移至右侧，aria-label 与回调不变；队列只保留已有计数，不伪造队列面板功能。`♪1/30`、收藏字符和失效 `!` 原文保留在 DOM，SVG/样式负责新外观；全部按钮的标签、禁用条件与点击行为沿用原值。多P与合集共用原跳过回调，不新建播放流程。audio 始终留在 Vue 宿主外。
