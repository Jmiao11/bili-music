# 游客 AAC 音质（Q-2）

本期仅增加游客 AAC 四档：最高可用（默认）、192K、132K、64K。设置经现有 settings adapter 存在 `bilibili-music.audio-quality`；缺失或无效值按最高可用读取，不改写旧值。保存只影响下一次主动播放/切歌，不中断当前媒体。播放栏文字入口显示实际返回的 192K/132K/64K；yt-dlp 为“兜底”，未知为“音质”；迷你窗不增加入口。

## 选轨与数据接线

| 请求档位 | 候选顺序 |
|---|---|
| highest / 192k | 30280 → 30232 → 30216 |
| 132k | 30232 → 30216 → 30280 |
| 64k | 30216 → 30232 → 30280 |

只识别以上三条 AAC 轨，特殊/未知 ID 忽略。先所选档，再向低档；没有低档则选高于目标的最低档。沿用原先无 DASH 时的 durl 兜底，durl 不虚构音轨 ID。

`prepare_audio` 显式接收请求档位，GuestPageHint 将其传至原位置的 select_audio；StreamAudioInfo/AudioResponse 传回 audioId（可空）和 isFallback。yt-dlp 只新增空 ID/兜底标记，不改命令、选轨、cookie、取消或兜底行为。网络执行顺序、游客身份/WBI、CDN 探测、代理/Range、现有请求核验和 auto 分支保持。

自动断流恢复使用已捕获的 preference，并显式携带当前 audioId；该 ID 在原缓存检查处精确查询，不受另一档备忘影响，远端选轨以该实际档位优先。缺轨仍按同一有限回退规则处理。拖动不更换媒体，若触发既有重连则沿用此参数。URL 不用于推断音轨。

## 实际音轨备忘与存储

媒体缓存键：`BV:CID:音轨ID`。缓存索引保持 version 1，增加可缺省的 `qualityMemos`：`BV:CID:请求档位 → {audioId, recordedAt}`，recordedAt 为 Unix 毫秒，7 天有效。备忘字段损坏/无效项按无备忘读取，整个索引读取失败沿用 prepare 的缓存未命中处理，不覆盖损坏文件。写入复用缓存索引锁及既有原子写入。

原位置的缓存检查：有效备忘指向的实际轨精确命中则返回；无备忘或过期时，highest/192k 查 30280，132k 查 30232，64k 查 30216。未命中即执行原远端流程，不在选轨后再插入缓存检查。有效备忘指向的文件缺失时同样走远端，不擅自用另一档文件替代。

仅远端成功且有真实 AAC ID 时更新备忘。写入在 ResolveCoordinator 的 current 互斥锁内核验有效任务，取消/新任务替换不能与旧备忘写入交错；保留原有两次身份核验，测试注入备忘写入端口不访问真实数据目录。备忘写失败不使成功取流失败。缓存命中不刷新备忘时间。

旧 `BV:CID` 缓存不用于新查找，不删除或迁移；容量淘汰继续处理旧项，清空时一并删除旧媒体和备忘。响度 command 保留 `key=BV:CID` 并显式传 audioId，Rust 在内部组成三段测量键；不读取/迁移旧测量值。未知 ID 的媒体不生成新缓存/测量记录。状态恢复、队列、收藏/歌单、歌词与播放记录身份保持原样。

## 播放栏音质入口补充

实际音质改为 28px 高、12px text3 的文字按钮和下拉箭头，与分 P 控件独立成组、间隔 12px。未知来源显示“音质”，yt-dlp 显示“兜底”。尚无当前歌曲时入口保持可见但禁用，不安装按钮监听；有当前歌曲（含等待/未知音轨）后启用。因此默认启动不增监听，G0 193/149 及 SHA 保持原样。

菜单在 AppShell 中独立于播放栏渲染，以按钮几何定位向上展开，避免播放栏层叠上下文、图像区域前景和裁剪影响。复用 floating-surface、dialog-shadow、FloatingBackdrop 及现有浮层几何观察端口，支持深浅色、背景图和动态主题。菜单只在打开期间挂载，点击外部、keydown 与 resize 监听同时安装，关闭时配对移除；resize 关闭以免留下过时位置。

控制器 root-playback.ts 负责焦点、几何读取和临时监听；组件只接只读 props/ref/回调。打开聚焦当前设置；上下方向键循环移动，Home/End 到首尾，Enter/空格选择，Esc 关闭并还焦点，Tab/外部点击关闭。选择直接复用 settings.setAudioQuality，不改当前实际轨或触发取流、媒体操作；设置页同步投影，下一次播放生效。迷你窗不改。
