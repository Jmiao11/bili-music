# 搜索状态

应用数据目录的 `search_state.json` 使用 version 1 和共用存储锁，按既有方式原子写入。启动时读取一次。文件缺失、解析失败或版本不符时按空缓存处理。文件只存搜索词、时间、列表元数据和分页游标。

`history` 保存最近 10 个成功的非空第一页搜索词。比较前去掉首尾空白并转小写，重复词移到最前，展示使用最近一次输入的大小写。删除或清空历史会保留缓存结果。

`lastResult` 保存关键词、分区、类型、保存时间、结果和分页游标。最新有效的第一页成功后替换，后续同条件的连续页追加已经在前端去重的条目。达到 100 条后停止写入追加项。最后一页只存下部分条目时，保留上一完整页的游标，重启后重新获取该页并去重，补齐未存下的条目。失败、风控和过期请求均无写入。

旧的 localStorage 关键词保留为无结果缓存时的启动草稿。既有 AI 搜索历史和备份继续使用 `search-history.json`，只在显式搜索成功后记录。设置里的清空操作清除这两套历史，搜索框菜单管理本地的最近 10 条。
